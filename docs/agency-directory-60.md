## 1. 왜 '진짜 듣보 / 초영세 기획사'가 100% 최우선 타깃인가?

* **대형/중견사 (하이브, SM, JYP, 스타쉽, 판타지오, FNC 등):**
  * 이미 전담 IT팀, 보안 가이드라인, 전용 인트라넷이 구축되어 있어 외부 신생 툴 도입 시 품의/보안 검토만 수개월이 걸립니다.
* **진짜 듣보 / 초소형 영세 기획사 (직원 1~4명 규모):**
  * **대표 1명 + 실무 매니저 1~2명**이 기획, 스케줄링, 음원 발매, 정산, 오디션 심사까지 모든 것을 혼자 처리합니다.
  * 홈페이지 개발비(수백만 원)나 IT 솔루션 구독료를 낼 예산이 전무하여 **무료 네이버 메일(`@naver.com`), 다음 메일(`@daum.net`), 한메일(`@hanmail.net`), 개인 지메일(`@gmail.com`)**에 100% 의존합니다.
  * **현장 병목:**
    1. 네이버 대용량 첨부 30일 만료로 유망주 영상 유실
    2. 구글 드라이브 비공개 권한 잠김 에러
    3. 10대 지원자 아이폰 `.MOV` 영상이 사무실 윈도우 PC에서 재생 불가
    4. 온뮤직/모던K 등 실용음악학원 내방 오디션 수십 명 압축파일 수기 정리 야근
  * **Enter-AX 0원 침투 제안:**
    * *"대표님, 오늘부터 오디션 영상 다운로드 1초도 하지 마세요. 초기비용 0원, 월비용 0원으로 지원자가 폰에서 바로 올리고 3초 만에 브라우저에서 넘겨보는 전용 웹보드를 10분 만에 무료 세팅해 드립니다."*
    * **"진짜 무료냐, 당장 써보겠다"며 100% 즉각 전환**되는 극단적 시장 적합성(PMF) 구간입니다.
