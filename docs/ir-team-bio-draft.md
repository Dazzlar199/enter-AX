# Enter-AX IR 팀 소개 문안 초안

현재 확인된 팀 구성은 김찬주 대표와 개발자 1명이다. 대표 경력은 본인 제공 정보이며, 개발자 상세 이력은 확인 전이다. 확인되지 않은 회사명, 성과, 계약, 수상, 자문 관계는 대외용 덱에 넣지 않는다.

## 대표 / 사업 리드

**한 줄 소개**: 김찬주 대표는 음악 프리랜서로 활동하며 녹음 스튜디오를 7년 운영했다.

**IR용 2문장**: 김찬주 대표는 음악 프리랜서로 활동하며 녹음 스튜디오를 7년 운영했다. Enter-AX에서는 제품 방향과 사업 개발을 맡고, 기획사 파일럿을 추진한다.

## 제품 / 기술 리드

**한 줄 소개**: 개발자 1명이 Enter-AX의 제품 개발과 기술 구현을 맡는다. 성명과 이전 경력은 확인 후 기입한다.

**IR용 2문장 초안**: [성명]은 [관련 개발 경력]을 바탕으로 Enter-AX의 제품 개발을 담당한다. 현재 프로토타입에서 지원자·기획사 화면과 분석·콘텐츠 처리 흐름을 확인할 수 있으며, 다음 단계에서는 고객 환경의 안정성·보안·처리 비용을 검증한다.

## 산업 자문 또는 GTM 협력

자문·제휴가 실제로 확정된 경우에만 추가한다. 확정 전에는 덱에 이름이나 소속을 넣지 않고, `현장 검증 역량 보강 계획`으로 설명한다.

## 확인할 정보

1. 녹음 스튜디오 이름과 운영 기간의 시작·종료 연도(현재 운영 중이면 시작 연도)
2. 김찬주 대표가 공개할 수 있는 대표 작업 또는 성과 1개
3. 개발자의 성명, 담당 영역, 직전 1~2개 프로젝트·소속과 기간
4. 개발자가 공개할 수 있는 대표 기술 성과 1개
5. 개발자 실명·회사명·사진의 투자자용 덱 공개 가능 여부

현재 덱은 `대표 1명 + 개발자 1명`으로 표기한다. 자문단·제휴사는 실제 관계가 확인될 때만 추가한다.
